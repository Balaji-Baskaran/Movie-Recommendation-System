# Movie Recommendation System

An AI-powered Movie Recommendation System built with a modern **React (Vite) frontend** and **Flask REST backend**.

## 🚀 Getting Started

### 1. Install Python Dependencies

```bash
pip install -r requirements.txt
```

### 2. Run the Flask Backend

```bash
cd backend
python app.py
```

The Flask API runs on `http://127.0.0.1:5000` (or custom port via `--port <port>` or `PORT` environment variable).
The health check endpoint is accessible at `http://127.0.0.1:5000/api/health`.

### 3. Run the React Frontend (Development Mode)

In a new terminal window:

```bash
cd frontend
npm install
npm run dev
```

Open your browser at `http://localhost:5173/`. Requests to `/api` are automatically proxied to Flask on port 5000.

---

## ⚡ Direct Production Serving via Flask

Flask can serve the built React app directly as a single-page application:

```bash
cd frontend
npm run build
cd ../backend
python app.py
```

Open `http://127.0.0.1:5000/` to use the full React interface directly from Flask.

## 🛠️ Build & Verification
